# made-by-quorum/tap

Homebrew formulae for Quorum.

```sh
brew install made-by-quorum/tap/qd
qd live
```

If Homebrew asks you to trust the tap first (Homebrew 7 does for third-party taps), run `brew trust made-by-quorum/tap/qd` and install again.

Always use the full name, `made-by-quorum/tap/qd`: Homebrew core has an unrelated formula called `qd`.

Prebuilt for Apple Silicon Macs and x86_64 Linux (glibc 2.39 or newer). The formulae here are generated by the release pipeline in the Quorum monorepo, so an edit made here is overwritten by the next release.
